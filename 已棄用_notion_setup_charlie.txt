Charlie 訂房合約產生器：Notion 端設定說明
═══════════════════════════════════════════

■ 一、合約資料庫要建立的欄位

【客戶基本資料】
  中文姓名          → 標題欄位（把預設的 Name 改名）
  護照英文姓名      → 文字
  西元生日          → 日期
  護照號碼          → 文字
  通訊地址          → 文字
  電話              → 電話
  Email             → Email
  陪客-大           → 數字
  陪客-小           → 數字
  緊急聯絡人        → 文字
  緊急聯絡人電話    → 文字
  過敏原            → 文字（有填會以紅字寫入第六條(八)
                      的告知紀錄；沒填則印手寫空格線）
  證件照網址        → URL（見注意事項 3）

【預算表】
  待產入住日期      → 日期
  待產天數          → 數字
  待產房型          → 單選（次臥房／主臥房／兩房公寓獨享）
  待產每日房費      → 數字
  預產期            → 日期
  月子入住日期      → 日期
  月子天數          → 數字
  月子房型          → 單選（同上三選項）
  月子每日房費      → 數字
  定金              → 數字

【自動產生（不用建欄位，網頁會自己算）】
  待產小計＝待產天數×房費、月子小計＝月子天數×房費
  總房費＝兩小計相加
  頭款＝總房費90%－定金、期款＝總房費10%
  最遲入住日＝待產入住日期＋5天

■ 二、「合約連結」公式欄位

新增一個公式（Formula）欄位，名稱「合約連結」，
內容如下（【網域】部署後換成正式網址）：

lets(
  days1, if(empty(prop("待產天數")), 0, prop("待產天數")),
  p1, if(empty(prop("待產每日房費")), 0, prop("待產每日房費")),
  days2, if(empty(prop("月子天數")), 0, prop("月子天數")),
  p2, if(empty(prop("月子每日房費")), 0, prop("月子每日房費")),
  dep, if(empty(prop("定金")), 0, prop("定金")),
  v, mod((days1 * p1 + days2 * p2) * 6271 + days1 * 7919 + days2 * 3571 + length(prop("中文姓名")) * 2137 + dep * 97, 100000),
  "https://【網域】/contract.html?n=" + prop("中文姓名")
  + "&en=" + prop("護照英文姓名")
  + "&bd=" + if(empty(prop("西元生日")), "", formatDate(prop("西元生日"), "YYYY-MM-DD"))
  + "&pp=" + prop("護照號碼")
  + "&addr=" + prop("通訊地址")
  + "&tel=" + prop("電話")
  + "&em=" + prop("Email")
  + "&ga=" + if(empty(prop("陪客-大")), "", format(prop("陪客-大")))
  + "&gc=" + if(empty(prop("陪客-小")), "", format(prop("陪客-小")))
  + "&ecn=" + prop("緊急聯絡人")
  + "&ect=" + prop("緊急聯絡人電話")
  + "&d1=" + if(empty(prop("待產入住日期")), "", formatDate(prop("待產入住日期"), "YYYY-MM-DD"))
  + "&days1=" + format(days1)
  + "&r1=" + format(prop("待產房型"))
  + "&p1=" + format(p1)
  + "&edd=" + if(empty(prop("預產期")), "", formatDate(prop("預產期"), "YYYY-MM-DD"))
  + "&d2=" + if(empty(prop("月子入住日期")), "", formatDate(prop("月子入住日期"), "YYYY-MM-DD"))
  + "&days2=" + format(days2)
  + "&r2=" + format(prop("月子房型"))
  + "&p2=" + format(p2)
  + "&dep=" + format(dep)
  + "&alg=" + prop("過敏原")
  + "&img=" + prop("證件照網址")
  + "&v=" + format(v)
)

■ 三、注意事項

1. 防偽驗證：公式裡的 v 是驗證碼，網頁端會用相同算式
   重算比對，改任何金額/天數/姓名參數都會被擋下。
   網址「不帶 v 參數」則進入預覽模式：可以看範本，
   但頁首會出現紅色「未驗證」警示條。
2. 空欄位的行為：沒填的欄位，合約上會印出手寫空格線，
   可以印出來手填（例如簽署區一律手填）。
3. 證件照網址「不能」用 Notion 上傳檔案的網址：
   Notion 檔案網址約 1 小時就失效，且 formula 抓不到。
   請把證件照上傳到穩定圖床（例如 imgur、雲端空間的
   公開直連），把「圖片直連網址」貼進此欄位。
   圖片會顯示在合約後段獨立一頁，壓上客戶姓名浮水印。
   （若圖床不允許跨域存取，網頁上看得到圖，但下載 PDF
   時該圖可能空白——用 imgur 直連可正常。）
4. 每一頁都會自動鋪上「（客戶名稱）專用」斜向浮水印。
5. 網址長度：所有欄位填滿＋中文經瀏覽器編碼後約
   1,500~1,800 字元，在安全範圍內；通訊地址等文字欄
   請避免填超長內容。
