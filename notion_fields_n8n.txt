Charlie 訂房合約（n8n 版）：Notion 資料庫欄位清單

【客戶基本資料】
  中文姓名          → 標題（把預設的 Name 改名）
  護照英文姓名      → 文字
  西元生日          → 日期
  護照號碼          → 文字
  通訊地址          → 文字
  電話              → 電話
  Email             → Email
  陪客-大           → 數字
  陪客-小           → 數字
  緊急聯絡人        → 文字
  緊急聯絡人電話    → 文字
  過敏原            → 文字（有填→紅字寫入第六條(八)告知紀錄；
                      沒填→印手寫空格線）

【預算表】
  待產入住日期      → 日期
  待產天數          → 數字
  待產房型          → 單選（次臥房／主臥房／兩房公寓獨享）
  待產每日房費      → 數字
  預產期            → 日期
  月子入住日期      → 日期
  月子天數          → 數字
  月子房型          → 單選（同上三選項）
  月子每日房費      → 數字
  定金              → 數字

【檔案與流程控制】
  合約方案          → 單選（Charlie／Yoyo／…，選項名稱待定）：
                      n8n 依此選擇對應的合約模板版本
  證件照            → 檔案（Files & media）：上傳客戶證件照
  合約 PDF          → 檔案（Files & media）：n8n 產好回填，不用手動碰
  產生合約          → 核取方塊（Checkbox）：勾選＝觸發 n8n
  合約狀態          → 單選（待產生／已產生／產生失敗）：
                      n8n 自動更新，人不用碰；完成後 n8n 會
                      把「產生合約」的勾自動取消，避免重複觸發

【自動計算（不用建欄位，n8n／模板會算）】
  待產小計、月子小計、總房費
  頭款（總房費90%−定金）、期款（總房費10%）
  最遲入住日（待產入住日期＋5天）

【手填區（合約印出後手寫，不建欄位）】
  第幾胎、自然產/剖腹產、自費醫師、自費醫院
  簽署區：乙方簽名、身分證字號、戶籍地址、簽約日期
  最遲入住的「幾時前」

【對照舊版的差異】
  不再需要：合約連結 formula、驗證碼、證件照網址（URL 欄位）
  ——n8n 直接從「證件照」檔案欄位抓圖，沒有網址過期問題
